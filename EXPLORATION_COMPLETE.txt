CRITICAL DATA STRUCTURES:
==========================

- lli_fid - Object FID
- lli_clob - Cached object (page cache)

KEY ALGORITHMS:
================

1. Open Handle Caching
   - First open: Get handle from MDS
   - Reopen: Reuse handle, refcount++
   - Close: Refcount--, release if zero

2. Intent Operations
   - Single RPC combines lock + operation
   - MDS performs operation and grants lock
   - Avoids separate lock acquisition RPC

3. Read-Ahead
   - Context-based: Learns access patterns
   - Adaptive: Grows window on sequential
   - Batches prefetch into large RPCs

4. Tiny Write Optimization
   - <PAGE_SIZE writes to dirty pages
   - No server RPC needed
   - Huge latency savings

5. Hash-based Readdir
   - Seek position = filename hash
   - Enables distributed directory striping
   - Overflow pages for hash collisions
